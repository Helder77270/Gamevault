## Chantier 6 — le jeu de test lourd et le mode d'emploi

### Ce qui a été publié (Base Sepolia, testnet)

- Édition **#4 « Stress Test 500 »** (studio GameVault Dev), 100 exemplaires,
  0.000001 ETH, revente autorisée (10 % studio).
- Build : **480 Mio** chiffrés, **121 morceaux de 4 Mio**,
  CID `QmTJ6tfcc13tknqu4s7VMXfznpZawWa7zd1Y8Lh73EsXmD`,
  sha256 `0xa94e2b37…ac589e` (inscrit on-chain). Épinglé sur IPFS (Pinata)
  et copié dans `ticketd/data/builds` (ticketd le sert en premier).
- **Licence #4 envoyée sur ton wallet** `0xbdde…3f02`.
- Le jeu reste jouable : c'est le jeu natif de test (`game/native-test`)
  suivi de 480 Mio de données de remplissage générées localement (flux
  AES-CTR déterministe, rien n'est téléchargé d'internet ; Windows ignore
  les données après l'exécutable).
- Coût : 4 transactions, une fraction de l'ETH de test du wallet de dev.
- Script : `npm run bigbuild -w @gamevault/ticketd` (lecture seule) /
  `-- --apply` (reprend là où il s'est arrêté, progression dans
  `ticketd/data/bigbuild.json`).

### Vérifié cette nuit (test Rust `download_big_live`, sur ticketd local)

- Téléchargement de 480 Mio **mis en pause à 25 % puis repris** :
  4,9 s au total en local (≈ 98 Mio/s, 4 morceaux en parallèle).
- **3 morceaux abîmés** (n° 21, 61, 101) : VÉRIFIER les détecte et ne
  retélécharge qu'eux ; empreinte finale conforme au contrat.
- **Serveur coupé** : 2 morceaux abîmés réparés **via les miroirs IPFS**
  (premier test réel du secours IPFS : ça marche).
- Correction trouvée en route : ticketd relisait le build entier pour
  chaque morceau demandé (à 500 Mo, intenable). Il sert maintenant les
  plages d'octets en flux depuis le disque.
- Lancement d'un gros jeu natif : la vérification sur disque est passée en
  flux, et le build chiffré est libéré dès qu'il est déchiffré (pic mémoire
  réduit d'environ 2/3). **Pas testé de bout en bout** : il faut ta carte
  appairée.

### Mode d'emploi pour toi

1. Lance AURA-64 (l'exe release). Le jeu « Stress Test 500 » apparaît dans
   ton **Game Shelf** (licence #4) et dans **Téléchargements › À installer**.
2. **Télécharger** → choisis le dossier GameVault du PC. Suis la carte des
   morceaux, les vitesses réseau et disque.
3. **Pause / Reprendre** en cours de route ; essaie aussi de **fermer
   AURA-64** au milieu puis de le rouvrir : le téléchargement reprend où il
   en était (morceaux déjà vérifiés gardés).
4. **Limite de vitesse** : Paramètres › Téléchargements (ou le mode faible
   débit, 2 Mo/s) — la vitesse affichée doit plafonner.
5. **Casser le jeu** : Paramètres › active le **mode développeur**, puis
   Game Shelf › vue **Stockage** › bouton **ABÎMER (DEV)** sur la ligne du
   jeu (3 morceaux abîmés, numéros affichés).
6. **Vérifier** : fiche du jeu ou vue Stockage › VÉRIFIER → seuls les
   morceaux abîmés sont retéléchargés, l'empreinte finale doit être
   « conforme au contrat ».
7. **Secours IPFS** : coupe ticketd (ou désactive les services locaux),
   abîme à nouveau, puis VÉRIFIER : les morceaux arrivent des miroirs IPFS
   (hachures violettes sur la carte des morceaux).
8. **Jouer** : insère ta carte, appaire si besoin, JOUER : une fenêtre de
   console du jeu natif s'ouvre.
